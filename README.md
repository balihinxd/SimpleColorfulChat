Colorful Chat Authors - это плагин для BetterDiscord, который автоматически раскрашивает имена пользователей в чате в разные цвета, делая групповые переписки более удобными для восприятия и чтения.

Установка
Способ 1: Ручная установка
Скачайте файл ColorfulChatAuthors.plugin.js
Поместите его в папку BetterDiscord:
Windows: %appdata%/BetterDiscord/plugins/
macOS: ~/Library/Application Support/BetterDiscord/plugins/
Linux: ~/.config/BetterDiscord/plugins/
Перезапустите Discord
Включите плагин в настройках BetterDiscord → Plugins
Способ 2: Через менеджер плагинов (если поддерживается)
Откройте настройки BetterDiscord
Перейдите во вкладку "Plugins"
Нажмите "Download Plugins"
Найдите "Colorful Chat Authors" и установите
